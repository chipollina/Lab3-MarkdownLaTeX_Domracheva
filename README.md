# Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта
## Краткое описание
В данной лабораторной работе были изучены основы Markdown-разметки
и базовое использование LaTeX для оформления документации проекта.
Были созданы примеры заголовков, списков, таблиц, ссылок, изображений,
блоков кода, цитат, а также математических формул.
