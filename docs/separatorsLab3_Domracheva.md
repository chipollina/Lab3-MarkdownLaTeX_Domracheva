Третий раздел
___
Markdown — это облегчённый язык разметки, который позволяет форматировать обычный текст с помощью простых и интуитивно понятных символов. Вместо громоздких HTML-тегов здесь используются привычные знаки: решётки (#) для заголовков, звёздочки или подчёркивания для выделения текста, дефисы и числа для списков
***
Основные возможности Markdown — это интуитивное форматирование текста с помощью простых символов (жирный, курсив, заголовки, списки, блоки кода), которое сохраняет читаемость исходного файла и легко конвертируется в HTML, PDF и другие форматы. Такой подход оптимален для технических заметок, документации, постов в блогах и README-файлов: синтаксис остаётся понятным даже без предпросмотра, а структура документа выстраивается естественным образом.
___
Вот пример форматирования. Заголовки:
# Заголовок 1
## Заголовок 2
### Заголовок 3
